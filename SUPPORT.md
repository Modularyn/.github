# Getting help

Help with Modularyn is self-service.

- **The documentation.** Each repository's README describes what it holds and how to build and test it, and the Community repository's [roadmap](https://github.com/Modularyn/modularyn/blob/main/ROADMAP.md) gives the planned order of work. When releases begin, each will carry its own documentation set.
- **Bugs and feature requests.** Open an issue in the repository concerned, such as [modularyn](https://github.com/Modularyn/modularyn/issues). Search the open and closed issues first.
- **Security problems.** Report them privately, never in an issue; see the [security policy](SECURITY.md).

Modularyn has no support commitment yet: there is no support offer, no staffed help and no promised response time.
