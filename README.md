# Modularyn/.github

This repository holds the Modularyn organization's public profile and the default community files that every Modularyn repository uses unless it has its own.

- [profile/README.md](profile/README.md): the profile shown on the [organization page](https://github.com/Modularyn).
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), [CONTRIBUTING.md](CONTRIBUTING.md), [SECURITY.md](SECURITY.md) and [SUPPORT.md](SUPPORT.md): the default conduct, contributing, security and support policies.
- [FUNDING.yml](FUNDING.yml): the sponsor button.
- [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE): the bug report and feature request forms, with blank issues turned off.
- [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md): the default pull request template.

Modularyn itself lives in [Modularyn/modularyn](https://github.com/Modularyn/modularyn).
