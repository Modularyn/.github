# Modularyn

Modularyn is a modular .NET application platform and CMS. It lets a team build a production application or a content-driven site from maintained modules while keeping ordinary .NET development, explicit business boundaries, portable data and control of its own deployment. Its CMS is a complete application built on the same module and extension model its users have.

The first profile is a modular monolith on .NET 10 and C# 14, with PostgreSQL, a React and TypeScript administration shell and a server-rendered Razor site. The product is planned as Modularyn Framework, Modules, CMS, Admin, UI, Studio, CLI, Generator, SDK and Connectors.

## Editions

- **Community** is the free foundation under the Apache License 2.0, commercial use included. It holds everything needed to build and run your own applications and sites, including payments and the complete CMS, and it is complete without the paid editions.
- **Standard** and **Pro** license the same paid modules, Standard for one person and Pro for teams and organizations: the SaaS commercial lifecycle, Studio, governed low-code and AI authoring, AI management and workflow. Their source is published for review under the PolyForm Noncommercial License 1.0.0, and it never becomes open source. Commercial use needs a license, and none is offered yet; there are no offers or prices.

Five rules apply to every paid service:

1. Every paid service has a self-hosted path at the edition that sells it.
2. No access to your applications or data requires a Modularyn account.
3. Moving between hosted and self-hosted loses nothing, in either direction.
4. Paid rights are verified offline and outlive Modularyn's servers.
5. Ending a subscription ends only the service, never self-hosting of covered releases or any Community right.

## Status

Modularyn is in planning. Nothing has been released. The first goal, G-01, sets the product and contract baseline: the coverage register, names and contracts, ownership rules, threat models, the first profiles, dependencies and the initial acceptance cases. The [roadmap](https://github.com/Modularyn/modularyn/blob/main/ROADMAP.md) lists the milestones in order, as plans rather than promises, with no dates.

## Get it

There is nothing to install yet. When the first release is published, it appears on the [releases page](https://github.com/Modularyn/modularyn/releases) of the Community repository, with its documentation set and checksums.

## Security

Report a vulnerability privately, never in a public issue: on the affected repository's **Security** tab, choose **Report a vulnerability**, or email modularyn@jasonfurr.com. No response time is promised. The [security policy](https://github.com/Modularyn/.github/blob/main/SECURITY.md) has the details.
